## 2. 现行出勤规则

2026-07-27 曾按客户当时描述使用同一个在册总人数推导安排出勤。客户 2026-07-29 明确白班和夜班是同一批人员的班次分配，不能让两个班次都从在册总人数分别计算，否则会出现白班加夜班约 250 人、但实际总人数不足 130 人的问题。

现行规则按班次独立计算：

```text
本班有效实际出勤 = 本班填报实际出勤 + 本班未入职 + 本班临时工
本班安排出勤 = 本班有效实际出勤 + 本班请假（不含病假） + 本班旷工
```

病假单独记录，不计入上式的“请假”；班次没有任何出勤数据时显示 `0`。当前规则版本为：

`production-daily-text-v4-2026-07-29`

规则版本已进入日报来源指纹，因此旧规则生成过的日报在再次生成时会新建版本，不会错误命中旧指纹。

## 3. 司机月汇总规则

月汇总先按司机姓名归组，再在司机组内按路线、车辆和出车类型展示明细：

- 同一司机只显示一个序号和一个姓名；
- 同一司机的不同路线保留为组内明细；
- 同一司机只生成一个月度小计；
- 不再因为路线不同重复显示同一姓名和多个司机小计。

自动化回归覆盖“同一司机、两条路线”的合并单元格和小计结构。
