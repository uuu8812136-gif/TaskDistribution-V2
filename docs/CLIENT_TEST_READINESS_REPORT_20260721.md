## 7. 客户测试建议顺序

1. 使用项目管理员账号登录“变速箱物流部”，核对首页、设备、运输、生产和出勤真实数据。
2. 新建专用测试任务，完成执行人提交、抄送审核、最终确认和延期流程。
3. 新建专用设备流程数据，依次测试盘点、点检、维修和闲置/停用/报废审批；测试记录名称统一增加客户测试前缀，便于清理。
4. 使用超级管理员验证全局只读，再进入具体团队执行允许的修改，核对审计记录。
5. 在微信开发者工具加载 HBuilderX 最新输出，完成扫码、相机、定位、拒绝授权、跨团队和只读场景，再安排真机复验。
6. 客户确认测试结果后，再制定旧数据迁移、客户宿主机部署、域名、备份调度和发布/回滚窗口。
