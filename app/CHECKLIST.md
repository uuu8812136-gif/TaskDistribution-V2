## 🎯 核心功能验证

### 延期申请完整流程 ✅
1. ✅ 主负责人在任务未完成且未过期时可申请延期
2. ✅ 选择延期天数（3/5/7/10/自定义）
3. ✅ 填写延期原因提交申请
4. ✅ 任务状态变为"待延期审批"
5. ✅ 管理员收到申请并审批
6. ✅ 批准后：任务时间延长，子任务同步延长
7. ✅ 拒绝后：任务保持原计划时间
8. ✅ 延期历史完整记录
9. ✅ 每个任务只能申请一次

### 子任务完整流程 ✅
1. ✅ 创建主任务时可添加多个子任务
2. ✅ 每个子任务可分配给不同的人
3. ✅ 子任务独立完成
4. ✅ 所有子任务完成后主任务才能完成
5. ✅ 主任务显示完成率
6. ✅ 主任务延期时所有子任务同步延期

### 团队任务完整流程 ✅
1. ✅ 分配多个执行人
2. ✅ 指定主负责人
3. ✅ 只有主负责人可申请延期
4. ✅ 所有成员完成后任务才能完成
